DiscordStreamTunnel · Guia que funciona offline

Primeira instalação, passo a passo

O programa encaminha o compartilhamento de tela do Discord por um túnel Proton WireGuard. A voz principal da chamada e os outros aplicativos continuam pela conexão normal.

1. Antes de começar

  1. Instale o Discord desktop nativo. O navegador, Flatpak e Snap não são cobertos por este instalador.
  2. Instale o Vencord no mesmo Discord, seguindo as instruções oficiais do Vencord. Depois de uma atualização do Discord, confirme que o Vencord continua instalado.
  3. Na sua própria conta Proton VPN, gere e baixe um arquivo de configuração WireGuard .conf. Consulte as instruções oficiais da Proton se precisar gerar o arquivo.
  4. Baixe o pacote do seu sistema na release oficial. Os links externos desta página precisam de internet; as instruções de instalação podem ser lidas offline.
Seu .conf contém uma chave privada. Não envie esse arquivo, a pasta data ou a pasta instalada a outras pessoas. Cada usuário deve usar a configuração da própria conta.

2. Instalar no Windows x64

  1. Extraia todo o ZIP DiscordStreamTunnel-VERSÃO-Windows-x64.zip para uma pasta. Não execute o programa de dentro do ZIP nem separe o .exe da pasta _internal.
  2. Encerre o Discord completamente, inclusive pelo ícone perto do relógio: clique com o botão direito e escolha sair.
  3. Abra DiscordStreamTunnel.exe, selecione seu arquivo Proton .conf e clique em Instalar / reaplicar.
  4. Aguarde a confirmação. A primeira instalação precisa de internet para baixar e verificar o núcleo de rede. Python já está incluído.
  5. Abra o Discord pelo atalho habitual, entre em uma chamada e assista a uma transmissão. O túnel começa a ser preparado em segundo plano ao abrir o Discord.

O executável ainda não tem assinatura Authenticode e o Windows pode mostrar um aviso de reputação. Confira a origem oficial do download e, se necessário, os hashes em SHA256SUMS.txt. Não é necessário desativar o antivírus ou o firewall.

O instalador e o aplicativo Proton podem ficar fechados depois da instalação. Use o programa com o mesmo usuário do Windows que utiliza o Discord.

3. Instalar no Linux

Use o Discord nativo e o Vencord. É necessário Python 3.10 ou superior.

  1. Extraia DiscordStreamTunnel-VERSÃO-linux.tar.gz pelo gerenciador de arquivos e abra um terminal na pasta extraída.
  2. Encerre completamente o Discord e execute, com seu usuário normal:
sh instalar.sh

Escolha Instalar / reaplicar e informe o caminho do seu .conf. Depois abra o Discord pelo atalho normal.

Se faltar Python, instale pelo gerenciador da distribuição:

# Ubuntu / Debian
sudo apt install python3 ca-certificates
# Arch / CachyOS
sudo pacman -S --needed python ca-certificates

A interface gráfica é opcional. Instale python3-tk (Ubuntu) ou tk (Arch/CachyOS) e, na pasta extraída, execute python3 source/app.py --gui.

Não execute instalar.sh com sudo. As bibliotecas do projeto já acompanham o pacote.

4. Verificar instalação e resolver problemas

“Vencord não encontrado” ou a integração parou após uma atualização

Confirme que o Vencord está instalado no Discord usado. Feche o Discord, abra o instalador e use Reparar. Se a instalação estiver incompleta, selecione novamente o .conf e use Instalar / reaplicar.

Tela preta, carregamento prolongado ou erro ao assistir

  1. Confirme que sua internet e o Discord estão funcionando e que o remetente continua transmitindo.
  2. Mantenha o Discord aberto durante a reprodução do problema. No instalador, clique em Verificar logo após a falha.
  3. Envie ao suporte somente o arquivo diagnostico.json indicado no resultado. Informe o sistema, a versão do Discord/Vencord, o horário aproximado, o código do erro e se o problema afeta uma ou todas as transmissões.
  4. Se o túnel não alcançar a Proton, teste uma configuração WireGuard de outro servidor disponível na sua conta. Feche o Discord antes de reaplicar a configuração.

O diagnóstico diferencia abertura do controle, tráfego UDP e descoberta inicial. Ele não contém o .conf, tokens, chaves ou conteúdo de mídia. Um status antigo indica que o auxiliar pode já ter encerrado; reproduza a falha com o Discord aberto.

No Linux, também é possível gerar o relatório pelo terminal:

python3 ~/.local/share/discord-stream-tunnel/launcher.py diagnose

Se você configurou XDG_DATA_HOME, ajuste o caminho para essa pasta. No Windows, o relatório normalmente fica em %LOCALAPPDATA%\DiscordStreamTunnel\data\diagnostico.json.

O túnel permanece preparado enquanto o Discord está aberto e usa verificações espaçadas. Isso mantém um pequeno consumo de memória e rede em segundo plano. Falhas da operadora, Proton ou Discord ainda podem exigir recuperação; não existe garantia de conexão sem interrupções.

5. Atualizar ou remover

Atualizações da integração são verificadas automaticamente. Quando aparecer o aviso no Discord, Reiniciar e aplicar encerra a chamada atual; você também pode adiar até a próxima abertura completa.

Para remover, encerre o Discord e clique em Desinstalar. No Linux:

python3 ~/.local/share/discord-stream-tunnel/launcher.py uninstall

Abra o Discord uma vez para restaurar a preferência anterior de vídeo. Seu .conf original permanece na pasta em que você o salvou.
